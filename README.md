# ABC University Annual Tech Fest 2025

A modern, responsive website for the **ABC University Annual Tech Fest 2025**, created to showcase the university's technology and cultural events, provide event information, and allow students to register for participation.

## 🌐 Website Overview

The website serves as the official digital platform for the tech fest, featuring a dark, modern interface with a professional navigation system and prominent event-focused sections.

The homepage welcomes visitors with:

> **ABC University Annual Tech Fest 2025**

It highlights the fest as a week-long celebration bringing together coding enthusiasts, robotics innovators, cultural participants, and technology enthusiasts.

## ✨ Features

* 🏠 **Home** – Hero section introducing the ABC University Annual Tech Fest 2025.
* ℹ️ **About** – Information about the tech fest and its purpose.
* 🎯 **Events** – Explore technical, cultural, and other fest activities.
* 📅 **Schedule** – View event dates, timings, and activities.
* 🤝 **Sponsors** – Showcase the organizations supporting the event.
* 📝 **Registration** – Dedicated section for participants to register.
* 📞 **Contact Us** – Provides contact information for event-related queries.
* 🎨 **Modern UI** – Dark-themed interface with blue accent buttons and a clean layout.
* 📱 **Responsive Design** – Designed to work across desktop, tablet, and mobile devices.
* 🔗 **Easy Navigation** – Navigation bar provides quick access to all major sections.

* Dark navy/black background

* Centered hero content
* Rounded call-to-action buttons

## 🎯 Project Objectives

The main objectives of this project are to:

* Create an attractive online presence for the university tech fest.
* Provide participants with important event information.
* Make registration easily accessible.
* Organize event schedules and activities in one place.
* Promote sponsors and fest partners.
* Provide visitors with an easy and intuitive browsing experience.
